# Реестр баз

Закрытое командное приложение на Google Apps Script. Базы — настоящие Google Таблицы в выбранной папке Google Диска; интерфейс и функции обновляются через GitHub.

В первой версии:

- дерево папок и таблиц с раскрытием и сворачиванием меню;
- создание папок и пустых баз в реестре, переименование баз;
- прямое редактирование ячеек, переход Enter/Tab и пустые строки для новых записей;
- сохранение в Google Таблицы, проверка конфликтов перед изменением ячейки;
- переключение листов и просмотр данных по страницам;
- открытие оригинала в Google Таблицах для расширенных операций;
- серверная проверка списка сотрудников и принадлежности файлов папке реестра.

## Первый запуск

Следуйте [инструкции подключения и публикации](DEPLOYMENT.md). Google Apps Script API включается владельцем один раз. Для первой загрузки кода требуется отдельная Google-авторизация через `clasp`; подключение Google Диска к чату её не заменяет.

До заполнения `ALLOWED_EMAILS` приложение закрыто для всех. Первичная настройка выполняется через **Project Settings → Script properties**, без запуска функций. Разрешённые адреса и административные настройки хранятся в Script Properties, а не в репозитории. Сотрудникам также нужны права на общую папку Диска.

В **Project Settings → Script properties** адреса указываются через запятую, без кавычек, например:

```text
ALLOWED_EMAILS = owner@example.com, member@example.com
ADMIN_EMAILS = owner@example.com
```

При первой настройке замените примеры своим Google-email и сохраните его в обоих свойствах. Добавьте `ROOT_FOLDER_ID` со значением `1WKcvDDKqYBo94eXsYc5vKp6OPtOzv6Wh`. Служебная функция `setupRegistry_` остаётся внутренним помощником; для запуска приложения выбирать её в редакторе не требуется.

## Обновления

Проверки запускаются для изменений в репозитории. Публикация из `main` включается после добавления Google-авторизации и ID существующего развёртывания. Новая версия переключает это же развёртывание, сохраняя адрес приложения. Открытые страницы получают новый интерфейс после обновления.

## Разработка

```sh
npm ci
npm run check
npm test
```

Исходники приложения находятся в `src/`, проверки и сценарии публикации — отдельно. `.clasp.json` содержит идентификатор проекта, но не данные авторизации.

## Границы первой версии

Сетка показывает ограниченное окно данных; остальные строки, столбцы и листы доступны через навигацию. Сложное форматирование, нестандартные форматы дат и чисел, объединённые ячейки, диаграммы и расширенные операции следует выполнять в оригинальном редакторе Google Таблиц.

Проверка версии ячейки отклоняет уже обнаруженные чужие изменения. Она не заменяет механизмы совместного редактирования Google Таблиц и не гарантирует транзакцию с параллельной записью из внешнего редактора. При конфликте приложение просит перечитать данные.

Приложение запрашивает разрешения Google для работы с Диском и Таблицами. OAuth-разрешения шире одной папки; ограничения реестра и команды дополнительно проверяет сервер приложения перед каждой операцией.

Автоматические проверки используют подменённые Google-сервисы. Первый живой вход и запись в Google Таблицу нужно проверить после развёртывания под аккаунтом владельца.
