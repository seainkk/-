# Меню задач в Google Таблицах

Это дополнение к сервису «Центр мультиканального аутрича». После установки в Chrome оно добавляет небольшую вкладку **«Задачи» слева** во все открываемые Google Таблицы. Нажатие раскрывает панель поверх страницы; стрелка сворачивает её. Значок расширения в Chrome тоже переключает панель. Если нажать значок на другом сайте, откроется сервис.

Внутри две заготовки: **«Провалидировать email»** и **«Распределить контакты»**. Кнопки отключены и пока ничего не выполняют. Ссылка **«Открыть Центр аутрича»** ведёт в существующее приложение команды:

## Установка для команды

Расширение подготовлено для ручной установки. Оно пока не опубликовано в Chrome Web Store.

1. Откройте [репозиторий](https://github.com/seainkk/-), нажмите **Code → Download ZIP** и распакуйте архив в постоянную папку на компьютере. Также можно распаковать отдельный архив расширения, если он передан вам коллегой.
2. Откройте `chrome://extensions` в Chrome.
3. Включите **«Режим разработчика»** справа вверху.
4. Нажмите **«Загрузить распакованное расширение»** и выберите папку **`extension`**, в которой лежит `manifest.json`. Для отдельного архива выберите папку с `manifest.json`.
5. Перезагрузите уже открытые вкладки Google Таблиц. В новых вкладках панель появится автоматически. При необходимости закрепите значок через кнопку расширений в Chrome.

Каждый участник устанавливает дополнение один раз в свой профиль Chrome. Перемещать или удалять установленную папку не следует. В рабочем браузере администратор организации может запрещать ручную установку; тогда способ распространения нужно согласовать с администратором.

## Что меняется в таблицах

Панель появляется во **всех Google Таблицах, которые участник открывает в этом браузере**, включая файлы вне папки реестра. На главной странице Таблиц и страницах опубликованных таблиц панель не появляется. Поддерживаются обычные ссылки и ссылки вида `/spreadsheets/u/0/d/…`.

Это интерфейс расширения поверх страницы, а не встроенное меню Google. Не нужно добавлять скрипт в каждый файл. Содержимое, размеры рабочей области и права доступа таблиц не меняются. В свёрнутом виде остаётся узкая вкладка слева; раскрытая панель временно закрывает часть таблицы. Её можно свернуть кнопкой, значком расширения или клавишей Escape, когда фокус находится в панели.

Расширение не читает и не редактирует ячейки, не вызывает Google API и не отправляет данные на сервер. Единственное дополнительное разрешение `storage` сохраняет локально, свёрнута ли панель. При первой установке она свёрнута. Разрешение на запуск ограничено страницами Google Таблиц; разрешения на все сайты, список вкладок, Google Диск и вход в Google не запрашиваются.

## Связь с текущей инфраструктурой

Код расширения хранится в том же GitHub-репозитории, в папке `extension`. Кнопка «Открыть Центр аутрича» открывает уже развёрнутое веб-приложение Apps Script. Файлы баз по-прежнему хранятся на Google Диске. Расширение не управляет входом: действуют доступ к веб-приложению, серверный список разрешённых пользователей и права на Google Диске. Получение архива расширения не даёт доступа к базам.

Репозиторий публичный, поэтому исходный код и адрес веб-приложения видны всем. Пароли, ключи, токены и приватные данные в расширение не включаются. Само это демо-меню не ограничено списком сотрудников; защита данных остаётся в приложении и Google Диске.

## Обновления

Интерфейс реестра обновляется через существующий процесс GitHub → Apps Script. Это не обновляет установленное расширение.

Для ручного обновления расширения скачайте новую версию, замените файлы в установленной папке, нажмите **«Обновить»** на его карточке в `chrome://extensions` и перезагрузите вкладки таблиц. В будущем распространение через Chrome Web Store или управляемую установку в организации позволит централизованно доставлять новые версии расширения. Этот архив сам по себе не включает автоматические обновления.

В проекте Apps Script настроен `rootDir: src`, поэтому папка `extension` не загружается в Apps Script и не влияет на развёртывание веб-приложения.

## Почему расширение

Обычная панель Apps Script в русскоязычном интерфейсе открывается справа и связана с конкретным файлом или устанавливаемым дополнением. Для меню слева, появляющегося во всех таблицах участника, выбран content script Chrome. См. официальную документацию: [Apps Script Ui.showSidebar](https://developers.google.com/apps-script/reference/base/ui#showsidebaruserinterface), [Chrome content scripts](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts), [Chrome tabs API](https://developer.chrome.com/docs/extensions/reference/api/tabs).

## Проверки демо

Автоматические тесты запускаются из корня репозитория командой `npm test`. Они проверяют адреса таблиц, работу сворачивания, неактивность задач, отсутствие вмешательства в содержимое таблицы и переход из значка расширения. Браузерная проверка проведена на макете страницы Google Таблиц с подставленным Chrome API. Установка расширения в настоящий рабочий профиль и проверка на реальных файлах требуют отдельной проверки после установки: облачный браузер запрещает такую установку политиками администратора.
